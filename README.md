# Curling Chaos 3D · Final Release

- 1 vs 1
- 2 vs 2
- CHAOS CUP -turnausrunko
- 4 pelihahmoa ja omat ominaisuudet
- Ruotsi AI
- tähtäys, voima ja harjaus

- pisteet ja paikallinen paras tulos
- täysin staattinen selainpeli, ei palvelinta eikä tietokantaa
